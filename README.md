# Zyatech Website

Official website for **Zyatech Private Limited** — Innovative technology solutions crafted to simplify everyday life.

## Project Structure

```
├── frontend/        # Next.js frontend application
│   └── src/
│       ├── app/
│       │   ├── page.js                     # Home page
│       │   ├── layout.js                   # Root layout (SEO, fonts)
│       │   ├── globals.css                 # Global design tokens & utilities
│       │   ├── privacy-policy/             # Privacy Policy page
│       │   │   ├── page.js
│       │   │   └── PrivacyPolicy.module.css
│       │   └── terms/                      # Terms of Service page
│       │       ├── page.js
│       │       └── Terms.module.css
│       └── components/                     # Reusable UI components
│           ├── Navbar/
│           ├── Hero/
│           ├── About/
│           ├── Products/
│           ├── Contact/
│           └── Footer/
├── backend/         # Backend (empty — planned for future)
└── README.md
```

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the website.

## Tech Stack

- **Frontend:** Next.js (App Router), React, CSS Modules
- **Backend:** Planned (Node.js / Express.js)
